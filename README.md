# 起身一下 · Mi Break

[MIT License](LICENSE) · macOS 14+ · Apple Silicon

本机 macOS 菜单栏久坐提醒器：米家扫码登录、座位传感器状态读取、全屏提醒、临时加班模式和按天记录。SwiftUI + AppKit 界面，Rust 云接口辅助进程。

## 当前验证边界

- 已构建 Apple Silicon `.app`，通过计时状态机测试、Rust 属性解码测试、Clippy 和 Swift 6 类型检查。
- 用户已完成扫码登录；实机读取到所选传感器的在座状态，账号和设备信息已在连接页显示。有人/无人完整转换与云端延迟仍待实测。
- 第一版按小米公开 MIoT 规格支持 `xiaomi.sensor_occupy.03`。其他型号能显示在候选列表，但不会套用这个型号的字段。
- 通过 `/home/device_list` 确认设备型号和云端在线标志，通过 `/miotspec/prop/get` 读取 `siid=2, piid=1078`：0 无人、1 有人、2 快检中（未知）。缺失、错误、未知值都不会解释成无人。
- 约每 15 秒读取，失败或超过 45 秒没有有效读取时停止推断。云端接口成功和在线标志不能证明传感器刚刚上报；云缓存、蓝牙网关和设备无人判定延迟均可能影响结果，需实测对照米家记录。第一版没有读取或补导米家历史事件。
- 原生界面已实测：快捷菜单展开、面板内记录页、前一天/今天切换、返回主面板和已登录信息展示。

## 使用

先按下方「构建与检查」从源码构建（目前没有签名、公证的安装包）。运行 `build/起身一下.app`，从主面板进入米家连接，点击「用米家 App 扫码登录」，在手机确认后选择座位传感器。云会话保存到本机钥匙串，设备列表里的其他设备不会写入日记录。

- 普通模式默认在座累计 45 分钟，离座目标 5 分钟，可调整。
- 主面板「去休息」可随时打开正式休息页；传感器确认无人后才开始累计，等待期间会显示状态和最近读取时间。「预览全屏提醒」保留在设置中。
- 回座需要有效的“有人”状态及最近 15 秒内的键盘、鼠标或触控板输入。已确认离座后，只路过或在附近休息而没有操作电脑，继续累计休息；已经确认在座后，停止输入阅读不会被算成休息。首次启动/暂停恢复后先等待确认，不猜算过去的休息。只查询系统事件时间，不记录按键内容或鼠标坐标。
- 离座暂停在座计时。喝水、上厕所等短暂离座保留本轮在座时长，离座时间可分次累计。
- 未满目标就回来，会全屏提示剩余休息时间。活动 1 分钟仍有价值，只是尚未达到所设目标。
- 本轮离座累计满目标后，在座计时清零，恢复普通模式；持续无人时保持为零，下一次有人才开始新一轮。
- 加班模式可把**本轮总在座时限**改为 60、90、120 分钟，不是从按钮点击时再延长相同时长。完成本轮休息后自动退出。
- 全屏提醒覆盖当前连接的显示器，保留「稍后 5 分钟」、临时加班以及 Esc 退出入口，不锁定系统输入。可以从主面板预览提醒。
- 睡眠、暂停、断网和程序关闭期间不自动算作休息；重新启动从未知状态等待新读取，保留未完成的一轮。
- 收起主面板仍在菜单栏运行；「退出应用」才停止记录。不自动配置开机启动。

## Atoll 刘海显示（可选）

在主面板右下角进入「连接与提醒」，开启「Atoll 刘海显示」。需要先运行 Atoll，并在其设置中开启扩展与本地 RPC 服务，首次允许「起身一下」显示活动。

- Atoll 接通时菜单栏只保留可点击图标，避免重复计时；关闭或断开后恢复菜单栏文字。
- 在座显示已坐分钟数；到点或短休息后提前回来时展开提醒。Atoll 的录屏、计时器等内置活动优先于第三方常驻活动，因此占位期间可能只看到短暂展开提示，不保证始终占据两侧。
- 离座显示剩余休息时间；补足目标后短暂显示完成，再收起。
- 暂停、睡眠或状态未知时撤下活动，避免显示失真的倒计时。正常退出使用独立、限时的本机连接清除活动，避免 SDK 断线重连竞争；强制结束进程无法保证执行清理。
- 可关闭「同时使用全屏提醒」；Atoll 未启用或连接不可用时仍回退到全屏提醒。
- 只向本机 Atoll 发送显示文字和计时状态，不传米家会话、设备 ID 或历史记录。可随时关闭开关；原有计时与记录不受影响。
- 使用官方 AtollRPC SDK，固定依赖修订于 `Package.resolved`；首次构建需联网获取。第三方许可见 `licenses/AtollRPC-MIT.txt`。

## 按天记录

「按天记录」在同一个菜单栏面板内切换，不另开窗口；可选择日期，查看累计在座、最长连续在座、离座时长、完成休息次数、加班在座时长，以及每段时间和提醒/模式事件。

- 按 Mac 当前本地时区拆分跨午夜时间段；统计是程序观测区间，不是精确的人体活动测量。
- “最长连续在座”在离座或未知时断开；提醒的“本轮在座”则保留短休息前后的累计，二者定义不同。
- 离座只能说明座位范围没有人，不能证明完成了运动。
- 每 30 秒及状态/操作变更时原子保存；正常退出再次保存。异常结束最多可能丢失最后一次保存后的记录。
- `~/Library/Application Support/MiBreakMenu/history.json` 保存设置、观测区间和模式事件，不含账号 Cookie、云 Token、设备 ID 或图像。
- 钥匙串服务 `MiBreakMenu` 保存登录会话与所选设备。退出米家登录删除该会话，保留历史记录。
- 若历史文件损坏，应用报错并停止覆盖原文件。

## 节奏依据

45 分钟 / 5 分钟是可调整的产品默认值，并非医学阈值。HSE 建议频繁短休息，例如每小时 5–10 分钟优于每两小时 20 分钟：https://www.hse.gov.uk/msd/dse/work-routine.htm 。加班模式是用户主动选择的临时例外，不表示久坐两小时属于推荐节奏。

## 构建与检查

需要本机 Swift 6.3、Rust/Cargo；不自动安装或升级系统依赖。最低 macOS 14，当前仅打包 ARM64。

```sh
git clone https://github.com/jasonlau111/mi-break-menu.git
cd mi-break-menu
./test.sh
./build.sh
open 'build/起身一下.app'
# 隔离的模拟预览：不读钥匙串、不访问米家、不读写真实历史
open 'build/起身一下.app' --args --preview
```

注意同一应用已运行时 `open --args` 不会切换实例模式，先从应用内退出再启动。构建使用本机 ad-hoc 签名，不是 Apple Developer ID 签名或公证。

## 结构

- `Timing/BreakEngine.swift`：计时、休息、加班、记录和每日统计的值类型状态机。
- `Sources/Model.swift`：云端状态、运行生命周期和保存协调。
- `Sources/Storage.swift`：钥匙串与历史文件。
- `Sources/Bridge.swift`：私有管道调用 Rust，取消和超时。
- `Sources/Views.swift`：主面板、全屏提醒和按天记录。
- `Sources/App.swift`：菜单栏、窗口和睡眠通知。
- `core/src/cloud.rs`：扫码登录、加密请求和型号专用只读解码。
- `Tests/BreakCoreTests`：离座补足、加班、未知/睡眠、延后、跨午夜、持久化往返测试。

## 协议来源与安全

扫码实现复用 `mi-air-menu`，上游参考 Xiaomi-cloud-tokens-extractor；保留 MIT 许可于 `licenses/`。只读 API 形状参考 hass-xiaomi-miot `a3a07b8504bacfee114a6052ae864d7dd149bf71` 的 `core/xiaomi_cloud.py`，未复制该仓库实现。

MIoT 规格：https://miot-spec.org/miot-spec-v2/instance?type=urn:miot-spec-v2:device:occupancy-sensor:0000A0BF:xiaomi-03:3 。`0/1/2` 的解释来自该型号 `occupancy-status`，并非凭截图推测。

非官方云端接口可能变化。只读设备状态，不调整设备配置、网关、网络或米家自动化。二维码用权限受限的临时文件，完成/取消后删除；凭据经应用内私有 stdin/stdout 管道传递，不要将真实核心请求/响应打印到日志或终端。
